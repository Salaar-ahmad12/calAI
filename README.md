CalAI is a React Native (Expo) mobile app that replicates the core experience 
of Cal AI — one of the App Store's highest-revenue health apps. Point your 
camera at any meal and get an instant AI-powered nutritional breakdown.

Built with:
- React Native + Expo (iOS & Android)
- Anthropic Claude Vision API (food recognition)
- React Navigation (bottom tabs)
- React Native SVG (macro rings & calorie ring)

Features:
- 📷 Photo → AI macro breakdown (calories, protein, carbs, fat)
- 📓 Daily food diary grouped by meal
- 💍 Macro progress rings
- 📊 Weekly calorie history chart
- 🔥 Streak tracking
- ⚡ Quick-add common foods

Built as part of a hackathon challenge to clone Cal AI using AI tooling.
